# Undangan Pernikahan (React + Vite)

1. Install: `npm install`
2. Jalankan: `npm run dev`
3. Build: `npm run build` (hasil di folder `dist/`)

- Edit teks/data/nama aset di bagian `DATA` pada `src/App.jsx`
- Taruh gambar & musik di `public/assets/` (lihat README.txt di dalamnya)
- Warna & lebar kolom ada di `:root` pada `src/App.css`
- Nama tamu: buka dengan `?to=Nama` di URL, contoh `http://localhost:5173/?to=Budi`
